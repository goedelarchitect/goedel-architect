- If your code contains the corresponding NEGATION theorem (named `<target>_negation`) with the canonical negation signature followed by `:= by …`, the system rebuilds under the negation statement: only your `:= by` proof body is kept; the same safeguards as the original-theorem path apply. This case registers a solve. Use this path only when, after compiler-grounded investigation, you become confident the original statement is false (e.g. a concrete counterexample that `lean_compile` confirms). Do not preemptively switch to the negation path.
